How it works

Three layers, kept separate

Keeping these apart is what lets one assistant serve many clients consistently. The process and format are written once. Only the profile changes from client to client.

1

The process layer

process.md

The five stages of the job and the standard for each, with a worked example of a strong finding and a weak one. Examples calibrate judgement better than long instructions.

Written once · changed carefully
2

The client layer

client-profiles/*.md

A short profile for each client with the brand, competitors, priority topics, social channels and approved sources. Nothing about method, only what to watch.

One per client · updated as focus changes
3

The output layer

report-format.md

The same fields in the same order on every report, so teams can scan quickly, compare week on week and spot what has changed.

Written once · rarely changed

Before you rely on them

What these skills can and can’t do

They support an analyst’s judgement and do not replace it. Review every report before it reaches a client.

They can

  • Follow the same process for every client, so reports are consistent
  • Search the public web for press coverage and public social posts on a client, its competitors and its topics
  • Filter, check and summarise, with a source link for every item
  • Skip items from the previous report, when it’s in the same project
  • Run on a schedule, and stop safely with a clear message if something’s missing
  • Draft client profiles and outreach lines for a person to review
  • Propose exact edits to the process when a report misses the mark

They can’t

  • See behind paywalls or logins, including LinkedIn. These are flagged for the team.
  • Guarantee they find everything. Coverage depends on your platform’s web search.
  • See every social post. Private accounts, stories and most comments are out of reach.
  • Monitor broadcast or print unless it’s published on the open web
  • Track numbers or alert on spikes. Use a monitoring tool for thresholds.
  • Remember earlier runs on their own
  • Send emails, post messages or contact anyone
  • Change your files or make decisions for you
Install

Up and running in minutes

The same ZIP files work in Claude and ChatGPT. Upload each skill you want separately, then run the short tests in the repository’s tests folder. Menu names can change, so check your platform's help centre if something has moved.

  1. Turn on code executionIn Settings › Capabilities, switch on file creation and code execution. On Enterprise plans, an owner enables Skills in organisation settings.
  2. Download a skillDownload the ZIP for the skill you want from above. Keep it zipped.
  3. Upload itGo to Customize › Skills, select +, then Create skill › Upload a skill, and choose the ZIP.
  4. Switch it onThe skill appears in your list. Make sure its toggle is on.
  5. Add your client profilesCreate a Project called “Client monitoring” and add your client profiles to its knowledge.
  6. Ask for a reportFor example, “Run today’s monitoring report for Northfield Coffee.” Claude loads the skill automatically.

Sharing with your team

On Team and Enterprise plans, open the skill in Customize › Skills, use the menu next to it and choose Share, or Publish to org to make it available to everyone.

Claude help: using skills

  1. Check Skills is availableSkills are on paid ChatGPT plans. On Business, Enterprise and Edu, your workspace owner may need to switch Skills on.
  2. Download a skillDownload the ZIP for the skill you want from above.
  3. Upload itSelect your profile icon, open Skills, choose Upload from your computer and select the ZIP.
  4. Check it’s installedThe skill appears under Installed, where you can manage it.
  5. Add your client profilesCreate a Project called “Client monitoring” and upload your client profiles to it.
  6. Ask for a reportFor example, “Run today’s monitoring report for Northfield Coffee.” Then set a scheduled task to run it each morning.

No Skills option?

Open the skill’s SKILL.md file, copy its contents into your Project instructions, and upload the files from its references and assets folders to the Project. The result is the same.

OpenAI Academy: skills

  1. Store the files in SharePointUnzip the skill and put its files, plus your client profiles, in a SharePoint or OneDrive folder called “Client monitoring”.
  2. Create an agentIn Microsoft 365 Copilot, create an agent and paste the contents of SKILL.md into its instructions.
  3. Add the folder as knowledgePoint the agent at your “Client monitoring” folder, and make sure web search is allowed.
  4. Ask for a reportFor example, “Run today’s monitoring report for Northfield Coffee.”
  5. Automate deliveryFor a report in Teams or by email every morning, build the agent in Copilot Studio and add a scheduled Power Automate flow.

Good to know

Copilot doesn’t install skill files directly, but the instructions inside them work as agent instructions. Your administrator may need to enable agent creation or web search.
