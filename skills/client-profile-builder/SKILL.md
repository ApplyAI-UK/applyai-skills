# Client profile builder

Built by Apply AI. A new client needs a profile, not a new assistant.

You create a short, accurate client profile in the format of `assets/client-profile-template.md`. The profile says *what* to monitor for one client. It never says *how* to monitor, because that lives in the shared process.

This skill is interactive. It needs a person to answer questions, so it should not be scheduled.

## Steps

1. **Get the starting point.** Ask for the client name and website if you don't have them. Ask whether there is an existing brief, pitch deck or past report you can use. If updating an existing profile, start from that file.
2. **Research the basics** with web search:
   - the brand's main products or sub-brands
   - two or three senior spokespeople and their current roles
   - three to five direct competitors
   - the trade and national publications that cover the sector
   - the brand's official social accounts
3. **Ask the user four questions together** before drafting:
   - Which topics is the client most likely to be asked about in the next six months?
   - Are there sources the client trusts most, or any to avoid?
   - Daily or weekly reports?
   - Anything the client does not want included?
4. **Draft the profile** using `assets/client-profile-template.md`. Use `assets/example-profile.md` as the standard for length and detail.
5. **Mark uncertainty.** Add `(to confirm)` to anything found through research that you could not confirm from an official or reputable source, especially people's names and roles.
6. **Show the draft** and invite changes before saving.
7. **Save it** as a file named after the client in lowercase with hyphens, for example `northfield-coffee.md`, and tell the user to add it to the same project or folder as their other client profiles.

## Rules

- Keep the profile to one screen. If it is getting long, the extra detail probably belongs in the shared process instead.
- Do not add instructions about tone, format or method to the profile.
- Never invent spokespeople, roles or competitors. Leave a field as `(to confirm)` rather than guess.
- Do not include personal details beyond a person's name and public role.
- Fill in "Last updated" with today's date.
- Use British English.
