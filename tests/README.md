# Testing the skills

Run these tests after installing a skill, and again after any change to it. Each test gives a prompt to send, the setup it needs, and what a pass looks like.

Use the example profile `templates/example-client-northfield-coffee.md` for monitoring tests. Northfield Coffee is fictional, so expect "no developments" for the brand itself. That's a useful test of whether the skill pads or invents.

For a real check, also run each monitoring test with one of your own client profiles and compare the result with what your team would have flagged.

| File | Skill |
|---|---|
| [client-monitoring.md](client-monitoring.md) | Client monitoring |
| [client-profile-builder.md](client-profile-builder.md) | Client profile builder |
| [new-business-signals.md](new-business-signals.md) | New business signals |
| [monitoring-calibrator.md](monitoring-calibrator.md) | Monitoring calibrator |

Record results in a simple table: test, platform (Claude or ChatGPT), pass or fail, notes.
